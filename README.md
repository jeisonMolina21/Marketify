# Marketify - Plataforma de E-commerce con Licenciamiento

Este es el entregable de maquetación de la interfaz gráfica para el proyecto **Marketify**. La aplicación ha sido desarrollada utilizando **Astro**, **React**, **Tailwind CSS** y **Lucide Icons** para ofrecer una experiencia premium, optimizada y accesible.

## 📦 Características Implementadas
1. **Landing Page:** Presentación de planes (Básico, Profesional, Empresarial) y formulario de autenticación.
2. **Panel del Comerciante (Dashboard):**
   - **Estadísticas:** Resumen visual de ventas y visitas.
   - **Productos:** Gestión de inventario (CRUD simulado).
   - **Órdenes:** Listado de pedidos recientes.
   - **Suscripción:** Estado del plan actual y gestión de pagos.
   - **Ajustes:** Configuración general de la tienda.
3. **Tienda Pública:**
   - Catálogo de productos con categorías y búsqueda.
   - Sistema de carrito de compras deslizable.
   - Simulación de proceso de pago (Checkout).
**Nota:** Este proyecto es un prototipo funcional de maquetación. Las interacciones son simuladas mediante el estado de React y no requieren una base de datos real para la demostración.
